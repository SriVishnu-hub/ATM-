#ATM Banking System in Python
Project Description

This project is a Python-based ATM banking system that simulates real-world ATM functionalities. Users can create an account, deposit and withdraw money, check balance, view transaction history, and change their PIN. It also uses SQLite3 for storing user account details securely.

#Features

Account creation with OTP-based activation.

Secure PIN verification for all transactions.

Deposit and cash withdrawal functionality.

Check account balance.

Change PIN securely.

Transaction history tracking with timestamps.

SQLite3 database integration to store account data.

#Technologies Used

Python 3

SQLite3 (for database storage)

time module (for timestamping transactions)
